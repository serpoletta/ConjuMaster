# ConjuMaster 🇫🇷

Тренажёр спряжения французских глаголов в настоящем времени
(Indicatif présent) с интервальными повторениями в духе Anki.

🌐 **Онлайн-демо:** https://serpoletta.github.io/ConjuMaster/

Открой — и учишь: карточки «русская фраза → французская форма», умный алгоритм
сам вернёт трудное раньше, а выученное — позже. Прогресс сохраняется между
визитами. Работает в любом браузере, устанавливается на телефон (PWA),
есть офлайн-режим.

## ✨ Возможности

- **245 глаголов · 2181 форма** настоящего времени; местоимения `il / elle / on` —
  отдельные карточки; у безличных глаголов (`falloir`, `pleuvoir`, `neiger`) —
  только форма `il`
- **Тренировки по 10 случайных форм**: на лицевой стороне карточки русская фраза
  («ты идёшь»), в углу кнопка-подсказка с инфинитивом; клик показывает правильный
  ответ и три кнопки — ✅ Верно · 🤔 Неуверенно · ❌ Неверно
  (горячие клавиши: `Пробел` — перевернуть, `1/2/3` — оценка)
- **Интервальные повторения**: верные ответы повторяются редко
  (интервалы 1 → 2 → 4 → 8 → 15 → 30 сессий), неуверенные — уже в следующей
  тренировке, неверные — как можно скорее плюс ещё раз в конце текущей тренировки
- **Статусы форм**: новая · в изучении · выучена (3 верных подряд) ·
  трудная (3+ ошибок; лечится тремя верными подряд);
  **статусы глаголов**: новый · в изучении · выучен (все формы) · со сложными формами
- **Календарь активности за год** в стиле GitHub contributions: число повторений
  по дням + серия дней подряд
- **Прогресс** хранится локально (localStorage) + экспорт/импорт JSON для переноса
  между устройствами; тренировка отдельного глагола и режим «только трудные»

## 🚀 Запуск

**Онлайн** — по ссылке-демо выше (рекомендуется, в т.ч. с телефона).

**Локально** — скачай репозиторий и либо просто открой `index.html` двойным кликом,
либо подними локальный сервер:

```powershell
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

**На телефон** — открой демо в Chrome Android → меню `⋮` → «Установить приложение»;
на iPhone: «Поделиться» → «На экран “Домой”». После первого визита работает офлайн.

## 🛠 Технологии

Чистый HTML + CSS + JavaScript без зависимостей и сборки. PWA: `manifest.json`,
иконки, `sw.js` (офлайн-кэш).

```
index.html          разметка и экраны (главная / тренировка / итог)
styles.css          светлая зелено-голубая тема, адаптив
app.js              карточки, SRS-алгоритм, статистика, календарь, localStorage
data.js             сгенерированные данные (не редактировать вручную)
top245verbsfr.txt   исходник данных: глаголы, спряжения, переводы
parse_verbs.py      генератор data.js из txt
```

## 📚 Данные

Исходник — `top245verbsfr.txt` (формат: `инфинитив — перевод`, далее
`форма — перевод` для каждого местоимения). Спряжения сверены с Le Conjugueur
(leconjugueur.lefigaro.fr), переводы — с частотным списком Quizlet топ-200.
Пересборка после правок txt:

```powershell
python3 parse_verbs.py
```

Id карточек привязаны к инфинитивам (`faire:tu`), а не к номерам строк,
поэтому порядок глаголов в файле можно менять без потери чужого прогресса.
