# ConjuMaster 🇫🇷

Локальное веб-приложение для отработки спряжения французских глаголов
в настоящем времени (Indicatif présent).

## Запуск

Вариант 1 — просто открыть файл в браузере:

```
index.html  (двойной клик)
```

Вариант 2 — через локальный сервер (рекомендуется):

```powershell
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Никаких зависимостей и сборки нет — только `index.html` + `styles.css` + `app.js` + `data.js`.

## Данные

- `top245verbsfr.txt` — исходный файл: глаголы, спряжения в настоящем времени,
  переводы на русский. Источник спряжений: Le Conjugueur (leconjugueur.lefigaro.fr).
- В файле 166 глагольных групп из `top200verbsfr-1.txt` + 79 из `top200verbsfr-1addition.txt`,
  всего 245 групп и 2181 форма (местоимения il / elle / on — отдельными
  карточками; у безличных глаголов falloir / pleuvoir / neiger — только форма il).
- `data.js` — автогенерация из txt: `python3 parse_verbs.py`.

## Как тренироваться

1. Нажми «Начать тренировку · 10» — получишь 10 случайных форм.
2. На лицевой стороне карточки — русская фраза («ты идёшь»).
   Кнопка **?** в углу показывает подсказку — инфинитив глагола.
3. Нажми на карточку — откроется правильный ответ и три кнопки:
   **✅ Верно · 🤔 Неуверенно · ❌ Неверно** (клавиши 1/2/3, пробел — перевернуть).
4. Неверные формы возвращаются ещё раз в конце той же тренировки.

## ANKI-механизм

- ✅ Верно — интервал растёт (1 → 2 → 4 → 8 → 15 → 30 сессий), серия `streak +1`.
- 🤔 Неуверенно — повтор уже в следующей тренировке, серия сбрасывается.
- ❌ Неверно — повтор как можно скорее + ещё раз в текущей тренировке, серия сбрасывается.
- Отбор 10 карточек — взвешенный случайный: трудные (вес 12) > в изучении (6) >
  новые (2.2) > выученные к повторению (3, только просроченные).
- Статус формы: **новая** (0 показов) · **в изучении** · **выучено** (3 верных подряд) ·
  **трудная** (3+ ошибок всего; лечится тремя верными подряд).
- Статус глагола: **новый** (не встречался) · **выучен** (все формы выучены) ·
  **сложный** (есть трудные формы) · **в изучении**.

## Прогресс

Хранится в `localStorage` (`conjumaster_v1`) — при следующем запуске продолжишь
с того же места. Кнопки «Экспорт/Импорт прогресса» — для переноса между браузерами.
Календарь активности на главной показывает число повторений по дням
за последний год (включая сегодня), а также серию дней подряд. Засчитывается
каждый ответ — даже если тренировка прервана.

## Дизайн

Приятные зелёные + голубые тона, светлый фон, крупные карточки, адаптивная вёрстка.
